# Folder publikasi GitHub Pages

Publikasikan **isi folder ini saja** ke root repository GitHub Pages. Jangan unggah folder aplikasi `monitoring-sdm`, file database, konfigurasi, backup, atau data sumber.

Sebelum publikasi pertama, pastikan `data/dashboard.json` sudah dibuat oleh skrip ekspor lokal, statusnya `ready`, dan isinya sudah ditinjau serta disetujui untuk publikasi. Jika file masih berstatus `not_exported`, website akan menampilkan keadaan belum tersedia tanpa angka contoh.

Lihat `../README_GITHUB_PAGES_ID.md` untuk petunjuk lengkap.
